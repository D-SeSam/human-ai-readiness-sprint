# Human-AI Readiness Sprint — V3

Stand: Juli 2026

Statische Webapp fuer den Human-AI Readiness Sprint.

## Nutzung

1. ZIP entpacken.
2. `index.html` im Browser oeffnen.
3. Sprint durchlaufen: Set, Choose, Challenge, Readiness-Karte.

## Output

- KI-Setup als Kurzprofil oder Arbeitsvereinbarung
- Test-Prompts zum schnellen Vergleich des KI-Setups
- Rollenentscheidungen fuer konkrete Aufgaben
- Sparring-Prompt
- KI-Readiness-Karte als persoenliche Zusammenfassung

Das KI-Setup kann kopiert oder als Markdown-Datei heruntergeladen werden. Die Readiness-Karte dient als Erinnerung, kann aber auch in einen Chat kopiert werden, damit die KI die bevorzugte Arbeitsweise beruecksichtigt.
